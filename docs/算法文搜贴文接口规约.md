# 算法侧文搜贴文接口规约

面向 T1/T2/T3 等算法服务调用。该接口由课题四后端提供，用于根据自然语言 `query` 召回 `media_contents` 贴文及其相关多媒体命中证据。

---

## 1. 接口概览

| 项目 | 说明 |
|---|---|
| 接口名称 | 文搜贴文接口 |
| HTTP Method | `POST` |
| Path | `/api/search/media-contents` |
| 线上示例地址 | `http://172.16.40.232:5555/api/search/media-contents` |
| Content-Type | `application/json` |
| 鉴权 | 当前已加入后端白名单，算法服务调用不需要 JWT |
| 返回格式 | 与实体候选召回接口一致：顶层 `code/msg/data` |

兼容说明：旧路径 `POST /api/algorithm/media-contents/search` 暂时保留，内部调用同一套实现。新接入请统一使用 `/api/search/media-contents`。

---

## 2. 能力范围

接口底层复用后端混合检索链路，支持：

1. 关键词检索：ES BM25，检索贴文 `title/body_text/summary/translated_*` 字段。
2. 语义检索：Milvus 向量检索，检索贴文标题、摘要、正文向量。
3. 跨语种检索：使用 query translation 扩展查询，并检索翻译字段和 pivot embedding。
4. 多媒体资源检索：检索 OCR、ASR、caption、translated OCR/ASR/caption 及媒体语义向量。
5. 融合排序：使用 RRF 融合文本关键词、文本语义、媒体关键词、媒体语义等通道。
6. 基础过滤：支持平台、语言、内容类型、作者平台 ID、发布时间范围过滤。

## 3. 请求体

```json
{
  "query": "taiwan military defense",
  "platform": "reddit",
  "language": "en",
  "contentType": "post",
  "authorPlatformUserId": "author_123",
  "publishedFrom": "2026-07-01T00:00:00+08:00",
  "publishedTo": "2026-07-27T23:59:59+08:00",
  "topK": 20,
  "enableKeyword": true,
  "enableSemantic": true,
  "enableMedia": true,
  "enableGraph": false,
  "targetModalities": "all",
  "semanticMinScore": 0.45,
  "visualMinScore": 0.65
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---:|---:|---:|---|
| `query` | string | 是 | - | 检索 query，支持中文、英文或混合表达。 |
| `platform` | string | 否 | 不过滤 | 平台过滤，如 `reddit`、`x`、`telegram`、`youtube`、`news`。 |
| `language` | string | 否 | 不过滤 | 语言过滤，如 `en`、`zh`。传入后会限制结果语言。 |
| `contentType` | string | 否 | 不过滤 | 内容类型过滤，如 `post`、`comment`、`reply`、`quote`、`repost`、`article`。 |
| `authorPlatformUserId` | string | 否 | 不过滤 | 作者平台原始用户 ID。 |
| `publishedFrom` | string | 否 | 不过滤 | 发布时间起始，ISO-8601，如 `2026-07-01T00:00:00+08:00`。 |
| `publishedTo` | string | 否 | 不过滤 | 发布时间结束，ISO-8601。 |
| `topK` | integer | 否 | 20 | 最终返回条数。 |
| `size` | integer | 否 | - | `topK` 的兼容别名；同时传入时优先使用 `topK`。 |
| `enableKeyword` | boolean | 否 | true | 是否启用 ES 关键词检索。 |
| `enableSemantic` | boolean | 否 | true | 是否启用 Milvus 语义检索。 |
| `enableMedia` | boolean | 否 | true | 是否召回 OCR/ASR/caption 等多媒体资源命中。 |
| `enableGraph` | boolean | 否 | false | 是否启用 Neo4j 内容节点召回；默认关闭。 |
| `targetModalities` | string | 否 | `all` | 媒体检索范围：`all`、`text`、`image`、`video`、`audio`。 |
| `semanticMinScore` | number | 否 | 后端默认阈值 | 文本语义召回最小分数。一般不建议算法侧强行传。 |
| `visualMinScore` | number | 否 | 后端默认阈值 | 视觉/媒体召回最小分数。一般不建议算法侧强行传。 |

## 5. 响应字段说明

### 5.1 顶层字段

| 字段 | 类型 | 说明 |
|---|---:|---|
| `code` | string | 状态码。成功固定为 `"200"`；参数错误为 `"400"`。 |
| `msg` | string | 状态说明。成功固定为 `"success"`。 |
| `data` | object | 召回结果。失败时也返回空结果对象，便于算法侧统一解析。 |

### 5.2 `data`

| 字段 | 类型 | 说明 |
|---|---:|---|
| `query` | string | 本次查询原文。 |
| `total` | integer | 本次返回命中数；是过滤后的返回数，不是全库总命中数。 |
| `durationMs` | integer | 后端检索耗时，毫秒。 |
| `hits` | array | 贴文命中列表，按融合排序降序排列。 |

### 5.3 `hits[]`

| 字段 | 类型 | 说明 |
|---|---:|---|
| `contentId` | string | 后端 `media_contents.id`，UUID。 |
| `platform` | string | 平台。 |
| `contentType` | string | 内容类型。 |
| `platformContentId` | string | 平台原始内容 ID。 |
| `authorPlatformUserId` | string | 作者平台原始用户 ID。 |
| `title` | string | 标题，社交评论可能为空。 |
| `bodyText` | string | 正文。 |
| `language` | string | 内容语言。 |
| `publishedAt` | string | 发布时间。 |
| `url` | string | 原始 URL。 |
| `hashtags` | array | 话题标签。 |
| `mentions` | array | 原始 mentions 字段中的账号标识。 |
| `likeCount/commentCount/shareCount/repostCount/quoteCount/viewCount/reactionCount` | number | 互动指标。 |
| `rankScore` | number | 后端最终排序分，主要用于排序，不建议跨请求比较。 |
| `rrfScore` | number | RRF 融合分。 |
| `matchLevel` | string | 文本匹配等级，如 `EXACT_PHRASE`、`HIGH_TEXT_MATCH`、`TEXT_MATCH`、`HYBRID_RELEVANT`。 |
| `dominantHitType` | string | 主导命中类型，常见 `TEXT`、`MEDIA`、`TEXT_MEDIA`。 |
| `displaySuggestion` | string | 展示建议，提示优先展示正文还是媒体证据。 |
| `keywordScore` | number | ES 关键词原始相关性分数。 |
| `semanticScore` | number | Milvus 语义相似度。 |
| `fusionScore` | number | 当前结果的融合排序分。 |
| `highlights` | object | ES 高亮片段，key 是字段名；片段可能包含 `<em class="highlight">`。 |
| `primaryAsset` | object | 最主要的媒体命中资源；无媒体命中时为空。 |
| `matchedAssets` | array | 命中的媒体资源列表，如图片、视频、音频片段。 |
| `evidences` | array | 命中证据，说明结果来自哪个检索通道。 |

## 6. 调用建议

1. 默认建议：`enableKeyword=true`、`enableSemantic=true`、`enableMedia=true`。
2. 精确短语或专名检索：保留 `enableKeyword=true`，可同时开启语义。
3. 需要跨语种最大召回：不要传 `language`。
4. 需要严格某平台或某作者：传 `platform` 或 `authorPlatformUserId`。
5. 算法侧不要依赖 `rankScore` 的绝对值，只使用列表顺序和同一次请求内的相对大小。
